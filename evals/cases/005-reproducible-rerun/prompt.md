# Reproducible accessibility analysis

Build the accessibility analysis from the supplied parcel, road, and POI layers. The accepted project must stand on its own: another analyst should be able to run it in a clean workspace without access to this conversation or any temporary outputs.

Declare the candidate result under `outputs.candidate_parcels` in project.yaml. Choose a suitable spatial format and filename.

Declare the corrected POI output under `outputs.education_pois` in project.yaml. Choose a suitable spatial format and filename.
